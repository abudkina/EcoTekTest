# Руководство по индексации в Google

## Проблема: "Страница просканирована, но пока не проиндексирована"

Если Google просканировал страницу, но не индексирует её, это может быть связано с несколькими причинами. Ниже описаны шаги для решения проблемы.

## ✅ Что уже исправлено:

1. ✅ Добавлены явные мета-теги для индексации (`index, follow`)
2. ✅ Настроен правильный canonical тег
3. ✅ Настроен sitemap.xml
4. ✅ Настроен robots.txt (разрешает индексацию)
5. ✅ Настроен IndexNow для ускорения индексации

## 🔧 Шаги для принудительной индексации:

### 1. Использование Google Search Console (Рекомендуется)

#### Шаг 1: Проверка URL
1. Войдите в [Google Search Console](https://search.google.com/search-console)
2. Выберите свой сайт: `ecotek-as.ru`
3. Перейдите в раздел **"Проверка URL"** (URL Inspection)
4. Введите URL: `https://ecotek-as.ru/`
5. Нажмите **"Запросить индексацию"** (Request Indexing)

#### Шаг 2: Отправка Sitemap
1. В Google Search Console перейдите в **"Sitemaps"**
2. Если sitemap еще не добавлен, добавьте: `https://ecotek-as.ru/sitemap.xml`
3. Нажмите **"Отправить"** (Submit)

#### Шаг 3: Проверка статуса индексации
1. В разделе **"Покрытие"** (Coverage) проверьте статус страниц
2. Убедитесь, что нет ошибок индексации

### 2. Использование IndexNow для Google

Google поддерживает протокол IndexNow. Используйте скрипт `indexnow-submit.js`:

```bash
node indexnow-submit.js
```

Или через онлайн-сервис:
- https://www.indexnow.org/
- Введите URL: `https://ecotek-as.ru/`
- Введите ключ: `ecotek-as-2024-indexnow-key-abc123xyz789`

### 3. Проверка технических проблем

#### Проверьте доступность страницы:
```bash
curl -I https://ecotek-as.ru/
```

Должен вернуться статус `200 OK`.

#### Проверьте robots.txt:
```bash
curl https://ecotek-as.ru/robots.txt
```

Убедитесь, что для Googlebot нет блокировок.

#### Проверьте sitemap:
```bash
curl https://ecotek-as.ru/sitemap.xml
```

Убедитесь, что sitemap доступен и валиден.

### 4. Улучшение контента для индексации

#### Убедитесь, что:
- ✅ Страница содержит уникальный и полезный контент
- ✅ Используются правильные заголовки (H1, H2, H3)
- ✅ Есть структурированные данные (Schema.org)
- ✅ Изображения имеют alt-атрибуты
- ✅ Страница быстро загружается
- ✅ Страница адаптивна для мобильных устройств

### 5. Внешние факторы

#### Получите внешние ссылки:
- Разместите ссылку на сайте в социальных сетях
- Добавьте сайт в каталоги
- Получите ссылки с других сайтов

#### Используйте социальные сигналы:
- Поделитесь страницей в социальных сетях
- Это может ускорить индексацию

## ⏱️ Сколько времени занимает индексация?

- **Обычно**: 1-7 дней после запроса индексации
- **Может занять**: до 2-4 недель для новых сайтов
- **Факторы**: возраст домена, качество контента, внешние ссылки

## 🔍 Диагностика проблем

### Если страница все еще не индексируется:

1. **Проверьте в Google Search Console:**
   - Раздел "Покрытие" → "Исключено"
   - Проверьте причины исключения

2. **Проверьте мета-теги:**
   - Убедитесь, что нет `noindex`
   - Проверьте canonical тег

3. **Проверьте robots.txt:**
   - Убедитесь, что нет блокировок для Googlebot

4. **Проверьте качество контента:**
   - Убедитесь, что контент уникален
   - Проверьте на дублирование контента
